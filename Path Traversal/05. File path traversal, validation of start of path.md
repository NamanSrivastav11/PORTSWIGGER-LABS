## Lab Description

This lab exposes an image-loading endpoint that accepts a user-controlled filename and then enforces access control by checking whether the resulting string starts with an expected base directory.

The defensive check is conceptually "prefix-based allowlisting", where any path begining with `/var/www/images` is considered safe.

This induces a weakness that the application validates the prefix before doing any canonicalization, so the path can still contain traversal segments that escape the trusted directory after resolution.
