## SOLUTION

---------------------------------------------

- Reference: https://portswigger.net/web-security/file-path-traversal

---------------------------------------------

In this lab, the application tries to sanitize path traversal by stripping `../` from user input.
The observed flaw was that stripping was done only once (non-recursive), so a crafted playload can still be processed into traversal after partial filtering.
