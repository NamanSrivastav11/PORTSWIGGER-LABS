## Lab Description & Analysis

The application enforces a brute-force protection mechanism that locks an account after a fixed number of consecutive failed login attempts.
If repeated failures occur for a valid account, the system transitions that account into a locked state and returns a response indicating the lockout condition.

The flaw lies in how this lockout behavior is applied. The lock is triggered only for valid usernames, since non-existent users do not have an associated account state to transition into. As a result, repeated login attempts with an invalid username will never produce a lock-related response, whereas valid usernames will eventually trigger an explicit **account locked** condition.
