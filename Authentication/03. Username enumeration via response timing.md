## Lab Description and Analysis

This lab focuses on exploiting response-time discrepancies in a login function to enumerate valid usernames. Although the application uses identical error messages and enforces IP-based blocking, but it trusts the `X-Forwarded-For` header which could allow us to potentially spoof our IP which can lead to a successfull brute force attempt.

- [Candidate usernames](https://portswigger.net/web-security/authentication/auth-lab-usernames)
- [Candidate passwords](https://portswigger.net/web-security/authentication/auth-lab-passwords)
